### 1. async def 函数、调用后得到的协程对象、await 得到的结果分别是什么？

```
async def 是创建一个协程函数。
调用这个协程函数，将会得到一个协程对象，只是创建，并不会执行函数。
通过await调用，才会真正执行并返回结果。
```

### 2. 事件循环在等待 I/O 时能做什么？为什么 async 不自动加速 CPU 运算？

```
事件循环在等待 I/O 时，会执行其他状态已就绪的任务。
async 是协作式并发，不是并行。
```

### 3. 顺序 await 与 gather 有什么区别？返回顺序与完成顺序是否相同？

```
顺序 await 是按顺序挨个执行，一个执行完再执行下一个，耗时是所有任务耗时的总和。
gather 是并发执行，总耗时是所有任务中耗时最多的那个任务的耗时。
返回值的顺序是一致的，完成顺序不一致。
```

### 4. 为何不能把 time.sleep 或同步 HTTP 调用直接放进 async 主流程？

```
会阻塞事件循环。
async 函数里，所有 I/O 必须用 async 版本，不能用同步阻塞调用。
```

### 5. 脚本里用 asyncio.run，notebook 中常用顶层 await，原因是什么？

```
普通脚本没有现成的事件循环，所有不能直接 await，而 asyncio.run 会创建新的事件循环，跑完就关闭。
notebook 能用顶层 await，是因为Jupyter 的 IPython kernel 自带事件循环。  
```

### 6. async with AsyncClient 负责什么？你的项目由谁创建、谁关闭客户端？

```
async with AsyncClient 负责创建/初始化客户端资源，关闭连接池，释放资源。
我的项目由调用方创建，由 async with 自动关闭客户端。
```

### 7. 为何 HTTP 200、合法 JSON、合法业务数据是三个不同判断？

```
因为它们属于不同的层级，HTTP状态属于网络层，JSON属于数据层，业务数据属于业务层。
各层级职责不同，校验是必须分开做的。网络层合法不代表JSON层就合法，JSON层合法不代表业务层也合法。
HTTP 200 是表示http请求的状态为成功，但是请求成功不代表响应的数据结构是合法的，数据结构合法并不代表数据合法。
```

### 8. HTTPX TimeoutException 与 RequestError 的关系是什么？为什么捕获顺序重要？

```
RequestError 是 TimeoutException 的子类，TimeoutException 承继 RequestError。
如果把 RequestError 放到 TimeoutException 前面，TimeoutException 将永远无法被捕获到，永远被误报为网络错误 
```

### 9. Protocol 和 PHP interface 有什么相似与不同？是否自动校验返回的 JSON？

```
相似处：
    1、定义契约
    2、声明方法签名
    3、实现者需符合
不同处：
    1、Protocol 是 duck 类型，不需要手动继承，结构符合即可，而 PHP 需要手动继承。
    2、PHP 需要显式声明，Protocol不需要。
    3、PHP 是类加载时检查，Protocol不检查。
不校验返回的数据，只是声明返回的数据类型而已。
```

### 10. FakeTransport 与 HTTPX MockTransport 分别替换哪一层？只测 Fake 会漏掉什么？

```
FakeTransport 替换的是 JsonTransport 协议，属于业务层。
HTTPX MockTransport 替换的是 http 底层的 transport，属于适配器层。

只测 Fake 会漏掉：
    1、适配器是否正确调用 httpx，因为 Fake 不涉及 httpx
    2、raise_for_status() 是否被调用，因为 Fake 不抛 HTTPStatusError
    3、JSON解析是否正确，因为 Fake 直接返回 dict，不解析
    4、URL编码是否正确，因为 Fake 只记录 URL，不验证编码
    5、超时是否传递给 httpx，因为 Fake 只记录 timeout，不会验证
    6、真实网络行为， 因为 Fake 完全是模拟的，不真实
```

### 11. 为什么 0 摄氏度不是“字段缺失”？为什么 bool 需要单独排除？

```
天气的温度本来就是零下，这是正常逻辑。
bool的底层是由 int 实现的，所以 isinstance(int, float) 判断时，会将其认定为是合法的int类型。
```

### 12. 怎样证明异步测试真的执行了业务？怎样验证 URL/timeout 被正确传递？

```
检查返回值，对返回值进行断言以及打印输出查看。
Fake 有记录 URL/timeout，通过 calls 可以查看。
```
